# Unity 2D RPG Demo

这是一个基于 Unity/C# 独立制作的 2D 横版动作 RPG Demo，主要用于熟悉 Unity 游戏开发流程、组件化开发、2D 物理、动画状态机、Prefab 配置、Canvas UI，以及游戏功能测试中的常见关注点。

## 项目内容

- 角色移动、跳跃、墙滑、墙跳、冲刺、普通攻击、连击、反击和死亡状态。
- 敌人巡逻、发现玩家、追击、攻击、眩晕、死亡和掉落逻辑。
- 属性与战斗系统，包括血量、攻击、防御、暴击、闪避、魔法抗性和火/冰/雷元素异常。
- 物品系统，包括掉落物生成、拾取、背包、材料仓库、装备穿戴、装备属性加成和装备效果。
- 合成系统，包括材料需求展示、材料数量校验、材料扣除和装备生成。
- 技能系统，包括冲刺、分身、飞剑、水晶、黑洞、技能冷却和技能树 UI。
- UI 系统，包括角色属性面板、背包、装备栏、合成界面、技能树、Tooltip 和血条显示。

## 测试关注点

- 功能测试：验证角色操作、敌人 AI、攻击命中、物品拾取、装备穿戴、材料合成和技能释放流程。
- 边界测试：验证背包容量、材料不足、技能冷却、敌人攻击距离、碰撞检测范围等场景。
- 异常验证：定位过掉落物悬浮、拾取后背包不显示、技能树 UI 颜色覆盖等问题。
- 调试方式：使用 Unity Console、Inspector、Scene/Gizmos 和断点调试进行问题复现、定位和回归验证。

## 主要技术

- Unity 2D
- C#
- Rigidbody2D / Collider2D / Physics2D
- Animator / Animation Event
- ScriptableObject
- Prefab
- Canvas UI / TextMeshPro
- 状态机模式

## 运行方式

1. 使用 Unity Hub 打开项目根目录。
2. 等待 Unity 自动恢复 `Library` 缓存。
3. 打开 `Assets/Scenes/SampleScene.unity`。
4. 点击 Play 运行。
